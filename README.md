# Undercover IRIS — Coming Soon

A dependency-free static landing page for `undercoveriris.io`.

## Preview locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Deploy

Upload the contents of this folder to any static host (Cloudflare Pages, Netlify, Vercel, GitHub Pages, or GoDaddy hosting). The domain DNS should point to the selected host. Do not share GoDaddy credentials; DNS changes can be made from your account using the records supplied by the host.
